MiPedido Setup

Configuración independiente · No modifica Google Sheets.

Procedimiento seguro
  1. Realice una copia de Google Sheets y del código Apps Script.
  2. Para un negocio nuevo, cree una hoja y configure el script autorizado.
  3. Para una instalación existente, conserve la hoja y la URL de implementación. No reinicialice.
  4. Configure js/config.js con la URL validada y use el instalador técnico únicamente si el servidor aún no está instalado.
  5. Compruebe acceso, locales, menú y pedidos antes de publicar.
Este asistente no concede permisos Google ni instala el servidor automáticamente.
